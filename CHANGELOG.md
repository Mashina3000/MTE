# CHANGELOG.md

## Локальная реализация вкладок 6–14 — 2026-10-12

- Добавлены настройки темы/языка/масштаба и локальные снимки состояния.
- Добавлен безопасный реестр манифестов плагинов; исполняемый код не запускается.
- Добавлены локальная очередь архивов, проверки SHA-256 и безопасных путей, экспорт ZIP.
- Добавлены инструменты генерации пиксельных узоров, локальная проверка совместимости и подготовка релизного ZIP.
- Добавлены офлайн-доска проекта, локальная консоль и встроенная справка.
- Внешние AI/облачные/публикационные/многопользовательские сервисы не подключены.

## Реализация вкладки 5 — Менеджер файлов

- Добавлены импорт файлов, папок и архивов ресурс-паков и экспорт рабочей области в ZIP.
- Добавлены поиск, фильтры, навигация по папкам, избранное, теги, сеточный/списочный вид и контекстные команды.
- Добавлены создание, переименование, копирование, перемещение drag&drop/вырезанием-вставкой, корзина и восстановление.
- Добавлены просмотр изображений и редактирование текстовых/JSON-файлов с историей версий.
- Добавлены SHA-256-поиск дубликатов, размеры и встроенные PNG/EXIF/XMP-метаданные, водяной знак/подпись.
- Рабочая область сохраняется локально через IndexedDB.

## [0.1.0] - 2024-10-09

### ✨ Новое

#### Проект
- Инициализирован проект Minecraft Texture Editor
- Установлена полная цепочка разработки (Vite, React, TypeScript)
- Настроена Electron сборка для десктопных приложений
- Создана GitHub Actions workflow для автоматической сборки .exe

#### Интерфейс
- Реализована система вкладок с 14 вкладками
- Горячие клавиши Ctrl+1...Ctrl+9 для переключения вкладок
- Тёмная тема интерфейса с использованием TailwindCSS
- Локализация: Русский и Английский языки

#### Zustand Store
- Создано модульное хранилище состояния
- Слайсы для: Editor, Animation, ResourcePack, UI
- Персистентное хранилище данных в localStorage

#### Вкладка 1: Редактор (✅ Полностью реализована)
- Canvas рисования с использованием Konva.js
- Инструменты: Карандаш, Ластик, Заливка, Пипетка
- Регулируемые параметры кисти:
  - Размер кисти (1-64 пиксела)
  - Жёсткость кисти (0-100%)
  - Форма кисти (квадрат, круг, ромб)
- Поддержка симметрии по осям X и Y
- Сетка для выравнивания
- Система слоёв:
  - Создание, удаление, дублирование слоёв
  - Управление видимостью и прозрачностью
- Выбор цвета (RGB/HEX пипетка)
- Пресеты размеров изображений (16, 32, 64, 128, 256, 512px)
- Импорт изображений (PNG, JPG, GIF, WebP)
- Экспорт в PNG

#### Вкладка 2: Анимация (✅ Полностью реализована)
- Таймлайн кадров с визуальной сеткой
- Управление кадрами:
  - Добавление, удаление, дублирование
  - Перемещение вверх/вниз
  - Индивидуальная длительность каждого кадра
- FPS контроль (1-120 FPS)
- Режимы цикла: Loop, Once, Ping Pong
- Экспорт .mcmeta файла для Minecraft
- Параметры анимации:
  - Общее количество кадров
  - Общая длительность анимации

#### Вкладка 3: Ресурс-пак (✅ Полностью реализована)
- Конструктор ресурс-пака
- Параметры пака:
  - Название, описание, автор, версия
  - Выбор шаблона (Empty, Medieval, Modern, Pixel Art и т.д.)
- Поддержка версий Minecraft:
  - 1.20.4, 1.20.3 Snapshot, 1.20.2, 1.20.1, 1.20 и старше
  - Автоматическое определение pack_format
  - Выбор одной или нескольких версий
- Валидация параметров пака
- Отображение структуры папок
- Генерация pack.mcmeta
- Экспорт пака

### 🔨 Инфраструктура

- **Vite** - быстрая сборка и dev сервер
- **React 18** - основной фреймворк
- **TypeScript** - strict режим типизации
- **TailwindCSS** - утилиты для стилей
- **Zustand** - управление состоянием
- **Konva.js** - рисование на canvas
- **i18next** - локализация
- **Electron** - десктопное приложение
- **electron-builder** - сборка инсталлятора
- **Vitest** + **Playwright** - тестирование

### 📦 Конфигурация Electron

- main.ts процесс с управлением окном
- preload.ts для безопасной коммуникации
- electron-builder конфиг для Windows (NSIS + Portable)
- Иконки приложения
- Menu с основными пунктами

### 🗂️ Структура проекта

```
minecraft-texture-editor/
├── src/
│   ├── components/      # Переиспользуемые компоненты
│   ├── tabs/           # 14 компонентов вкладок
│   ├── store/          # Zustand хранилище
│   ├── types/          # TypeScript типы
│   ├── utils/          # Утилиты
│   ├── locales/        # i18n локализация
│   ├── App.tsx         # Главный компонент
│   └── main.tsx        # Entry point
├── electron/           # Electron приложение
├── .github/workflows/  # GitHub Actions
├── dist/              # Собранное приложение
└── [конфиги]         # vite, tsconfig, tailwind и т.д.
```

### 🚀 Как начать

#### Разработка
```bash
npm install
npm run dev
npm run electron:dev
```

#### Сборка .exe
```bash
npm run dist:exe
```
