# Minecraft Texture Editor

Профессиональный редактор текстур для Minecraft ресурс-паков. Создан на React + TypeScript с поддержкой Electron для десктопных приложений.

## 🎨 Возможности

### Основные инструменты
- **Редактор текстур** - полнофункциональный редактор с поддержкой слоёв, фильтров и эффектов
- **Редактор анимации** - создание и редактирование анимаций для текстур
- **Конструктор ресурс-паков** - быстрое создание ресурс-паков с нужной структурой
- **3D предпросмотр** - просмотр текстур на блоках, предметах и персонажах
- **Менеджер файлов** - управление структурой ресурс-пака
- **Импорт/Экспорт** - поддержка различных форматов

#### Менеджер файлов

Вкладка «Файлы» хранит рабочую область локально в IndexedDB. Можно импортировать файлы,
папку или архив ресурс-пака (ZIP/MCPACK/MCADDON/MRPACK/JAR), просматривать и редактировать
текстовые файлы, перемещать элементы перетаскиванием или командами «Вырезать/Вставить»,
добавлять теги, отмечать избранное, искать дубликаты по SHA-256 и экспортировать структуру в ZIP.
Удалённые элементы попадают в корзину; изменения сохраняют историю до 20 версий. Для изображений
доступны предпросмотр, размеры, встроенные PNG/EXIF/XMP-метаданные и нанесение текстовой подписи.
Рабочая область не меняет исходные файлы на диске; для получения изменённого пака используйте экспорт.

#### Вкладки 6–14: офлайн-инструменты

- **Настройки:** тема, язык, масштаб, параметры приватности/производительности и локальные снимки состояния.
- **Плагины:** безопасный реестр JSON-манифестов; импортированный код не запускается.
- **Импорт/Экспорт:** локальная очередь архивов, проверка путей и SHA-256, экспорт проверенного ZIP.
- **Помощник текстур:** локальные пиксельные узоры/палитры, уменьшение изображения и экспорт PNG; это не подключённая AI-модель.
- **Совместимость:** проверка структуры и `pack.mcmeta` по редактируемой локальной таблице версий.
- **Подготовка публикации:** генерация метаданных/документов, ZIP и чек-листов для ручной публикации.
- **Команда:** локальная доска участников, комментариев и ревью; без синхронизации с другими пользователями.
- **Консоль:** локальный журнал приложения с фильтрами и экспортом.
- **Помощь:** поиск по встроенным инструкциям и создание локального черновика обратной связи.

Облачные диски, маркетплейсы, внешние AI API, автоматическая публикация и совместная работа в реальном
времени не подключены. Для таких сервисов понадобятся соответствующие API и отдельная серверная
инфраструктура.

### Дополнительные возможности
- Горячие клавиши (Ctrl+1...Ctrl+9 для переключения вкладок)
- Многоязычный интерфейс (Русский, Английский и др.)
- Автосохранение
- История изменений (Undo/Redo)

## 📦 Сборка .exe для Windows

### Локально (на Windows)

```bash
npm run dist:exe
```

Готовый установщик находится в папке `dist/`.

### Автоматически (GitHub Actions)

Node.js не нужно устанавливать на свой компьютер: сборку выполняет GitHub Actions. Сначала создайте на GitHub пустой репозиторий (не добавляйте к нему README или лицензию), затем откройте Git Bash в папке проекта и выполните команды. Замените `ВАШЕ_ИМЯ` и `ИМЯ_РЕПОЗИТОРИЯ` на свои данные:

```bash
git init -b main
git add .
git commit -m "Upload Minecraft Texture Editor"
git remote add origin https://github.com/ВАШЕ_ИМЯ/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Когда отправка завершится, откройте репозиторий на GitHub, перейдите в **Actions** и выберите запуск **Build Windows Installer** → **Run workflow**. Дождитесь зелёного статуса, откройте завершённый запуск и скачайте артефакт **windows-exe**. В нём будут установщик и портативная версия `.exe`.

В дальнейшем отправляйте изменения командами `git add .`, `git commit -m "Описание изменений"` и `git push`. Сборка запускается автоматически при отправке в ветку `main`. Чтобы GitHub также создал страницу Release для версии, отправьте тег, например:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Выполняйте команды из папки `F:\minecraft-texture-editor`. Если GitHub запросит вход, авторизуйтесь в открывшемся окне браузера. Node.js используется только на удалённом компьютере GitHub Actions, а не устанавливается на ваш ПК.

## 🔧 Конфигурация Electron

### Информация о приложении

В `package.json` секция `build` содержит параметры для Electron Builder:

- **appId** - уникальный ID приложения
- **productName** - название приложения
- **version** - версия приложения
- **win.target** - цели сборки для Windows (NSIS installer + portable)
- **nsis** - параметры NSIS инсталлятора

### Иконки

Поместите иконку приложения в папку `electron/`:
- `icon.ico` (для Windows, 256x256 или больше)
- `icon.png` (для других платформ)

## 🐛 Решение проблем

### Ошибка: "electron not found"
```bash
npm install
```

### Ошибка при сборке .exe
- Убедитесь, что вы на Windows
- Установите Node.js LTS
- Очистите кэш: `npm cache clean --force`
- Переустановите зависимости: `rm -r node_modules package-lock.json && npm install`

### Dev сервер не запускается
Проверьте, что порт 5173 свободен:
```bash
# Windows
netstat -ano | findstr :5173

# macOS/Linux
lsof -i :5173
```

## 👨‍💻 Разработка

### Добавление новой вкладки

1. Создайте компонент в `src/tabs/MyNewTab.tsx`
2. Импортируйте в `src/App.tsx`
3. Добавьте в массив `tabs`

### Добавление нового языка

1. Создайте файл `src/locales/de.ts` (например, для немецкого)
2. Импортируйте в `src/locales/i18n.ts`
3. Добавьте в ресурсы i18n
